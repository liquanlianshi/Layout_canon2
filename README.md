# AI × 新质生产力 · 数据可视化网站

> 一个用 **30+ 组可视化元素（含 28 个可交互 ECharts 图表）** 回答「人工智能作为新质生产力的作用和意义」的多页面数据网站。
> 纯静态（HTML / CSS / 原生 JS + 本地内置 ECharts），零构建、可离线运行、可直接部署到任意静态托管。

## 一、如何运行

**方式 A（最简单）**：直接双击 `index.html`，用浏览器打开即可（所有依赖已本地化，无需联网）。

**方式 B（推荐，本地预览服务）**：

```bash
cd 项目目录
python tools/preview.py 8080       # 白名单预览服务：只暴露站点文件，其余路径一律 403
# 浏览器访问 http://127.0.0.1:8080/
```

> 也可用 `python -m http.server 8080` 起服务，但那样会把整个项目目录（含中间产物与私有文件）
> 暴露给本机浏览器，因此推荐用 `tools/preview.py`（仅绑定 127.0.0.1、路径白名单、校验 Host 头）。

**部署**：把整个文件夹上传到 GitHub Pages / Vercel / Netlify / 任意静态服务器即可，无需任何构建步骤。

**自测（可选）**：

```bash
python -m pytest tests/ -q           # 自动化校验（结构 / 资源 / 图表绑定 / 插件加载 / 配色规范）
python tools/check_pages.py --shots  # 无头浏览器逐页检查并生成整页截图（需 playwright）
python tools/audit_colors.py .reasonix/scratch/screenshots   # 审计渲染结果的饱和度分布（需 Pillow + NumPy）
python tools/package.py              # 生成 docs/screenshots 配图 + 源码压缩包（需 Pillow）
python tools/verify_release.py       # 把压缩包解压到干净目录并核对清单（交付验收）
python tools/make_report.py          # 重新生成 docs/亮点说明.pdf（HTML → Edge 打印，需 playwright）
```

## 三、关键亮点

### 1. 内容亮点：一条完整的论证链

- **从概念到证据**：先用「三要素」框架解释 AI 为什么属于新质生产力，再用产业规模（宏观）、
  行业渗透（中观）、劳动力变革（微观）三层证据支撑，最后落到政策与治理边界。
- **数据分层标注**：站点严格区分三类数据 ——
  ① 官方统计（工信部、CNNIC、人社部等）；
  ② 第三方研究（WIPO、WEF、IDC、GitHub、BCG、麦肯锡）；
  ③ 示意性相对评估（如渗透热力图、成熟度雷达），并在图表下方明确标注，避免误读。
- **用可视化讲抽象概念**：桑基图解释「技术如何变成钱」，瀑布图解释「岗位净增 7800 万怎么来的」，
  S 曲线解释「为什么现在是加速期」，象限图解释「哪些 AI 赛道已在赚钱」。

### 2. 可视化亮点：28 个可交互图表，覆盖 13 种图表类型

折线/面积图、柱状图、瀑布图、横向条形图、热力图、桑基图、雷达图、环形图、仪表盘、
象限散点图、地图涟漪散点（effectScatter）、词云、markArea/markLine 标注 —— 每种图表都服务于内容，
而不是为炫技而炫技。

技术实现上：

- **统一主题**：`echarts.registerTheme("aura")` 一处定义全站图表的字体、坐标轴、提示框、图例样式；
- **懒初始化**：图表进入视口前不渲染（`IntersectionObserver`），长页面滚动依然流畅；
- **自适应**：监听窗口尺寸变化统一 `resize()`，移动端断点适配；
- **无障碍**：支持 `prefers-reduced-motion`（关闭动画）、语义化标签与 `aria-label`。

### 3. 设计亮点：多彩低饱和度，且「可验证」

按要求实现「颜色鲜艳、低饱和度」——做法是**统一饱和度与明度、只变化色相**：

| 维度 | 取值 | 效果 |
| --- | --- | --- |
| 主色饱和度 | HSV S ≈ 0.47（HSL S = 52%） | 柔和、不刺眼 |
| 主色明度 | HSL L = 63% | 保持鲜活，不灰暗 |
| 色相跨度 | 352° → 292°，覆盖 ≥ 300° | 8 个色相环均匀分布，依然「多彩鲜艳」 |

配色不是拍脑袋选的，而是由 `tools/make_palette.py` 生成，并有 **pytest 断言守护**：
任何主色饱和度超过 60%、色相跨度不足、明度越界，或者重新引入截图里那种高饱和蓝（如 `#2445EA`），
测试都会失败。此外全站采用浅色柔光基调：白卡片 + 22px 大圆角 + 柔和投影 + 细描边。

### 4. 工程亮点：零构建 + 自动化校验

- **零构建、零 CDN 依赖**：ECharts、词云插件、中国地图 GeoJSON 全部本地化到 `vendor/`，
  断网也能完整运行 —— 这让「提交源代码压缩包」即可复现全部效果。
  `vendor/SOURCES.json` 记录每个依赖的来源与 sha256，
  `python tools/setup_vendor.py --verify` 可联网核对本地文件与上游 CDN **字节级一致**。
- **自动化校验**（`tests/test_site.py`）：
  - HTML 标签闭合、`title`/`description`/`viewport`/导航/页脚完整性；
  - 所有本地资源引用真实存在（防止 404）；
  - 每个图表容器都能在 JS 中找到 `registerChart` 绑定（防止漏绑 / 空图）；
  - 运行时插件（词云 / 中国地图数据）与其使用页面同步加载（防止浏览器报错）；
  - 图表 id 跨页唯一；调色板 CSS 与 JS 一致；
  - 低饱和度、多彩、明度区间、无高饱和色回归。
- **可复现的工具链**：`tools/make_palette.py` 生成调色板，`tools/setup_vendor.py` 下载依赖，
  `tools/check_pages.py` 无头浏览器逐页检查。
